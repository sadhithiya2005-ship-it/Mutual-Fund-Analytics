# Git & GitHub Assignment

## Objective
To understand Git and GitHub basics and maintain version history for project assignments.

## Git Concepts Learned

- Repository – stores project files and version history.
- Clone – downloads a repository to the local computer.
- Commit – saves changes to Git history.
- Push – uploads local changes to GitHub.
- Pull – downloads the latest changes from GitHub.
- Branch – separate development path for making changes.
- Pull Request – request to merge changes into another branch.
